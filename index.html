The idea

We want a number \(r\) where \(f(r) = 0\): a root of \(f\). Solving the equation exactly is often impossible, so Newton's Method does something simpler. Start with a guess \(x_0\). Near that guess, the curve looks almost like its tangent line, and finding where a line crosses the x-axis is easy. Use that crossing point as the next guess, and repeat.

The tangent line at \(x_n\) is

\[ y = f(x_n) + f'(x_n)\,(x - x_n). \]

Setting \(y = 0\) and solving for \(x\) gives the next guess:

\[ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}. \]

In the graph above, each step draws a dashed line up from the current guess to the curve. It then draws the tangent line there and follows it down to the x-axis, where the next guess lands.

How fast does it converge?

When Newton's Method works, it works remarkably fast. Take \(f(x) = x^2 - 2\), whose positive root is \(\sqrt2 = 1.41421356237309\ldots\), and start at \(x_0 = 1\):

The number of correct digits roughly doubles with each step. This is called quadratic convergence. If \(e_n = x_n - r\) is the error after step \(n\), then

\[ e_{n+1} \approx \frac{f''(r)}{2f'(r)}\, e_n^{\,2}. \]

Squaring a small number makes it much smaller. An error of \(10^{-3}\) becomes about \(10^{-6}\), then \(10^{-12}\). By comparison, the bisection method (repeatedly halving an interval that contains the root) gains only about one digit every 3.3 steps. Why the error gets squared

Expand \(f\) around the current guess using Taylor's theorem, and evaluate it at the root \(r\):

\[ 0 = f(r) = f(x_n) + f'(x_n)(r - x_n) + \tfrac12 f''(\xi)(r - x_n)^2 \]

for some \(\xi\) between \(x_n\) and \(r\). Divide by \(f'(x_n)\) and use the definition of \(x_{n+1}\):

\[ x_{n+1} - r = \frac{f''(\xi)}{2f'(x_n)}\,(x_n - r)^2. \]

The tangent line is exactly the first two terms of the Taylor series. The only error comes from the curvature term, which is proportional to the square of the distance from the root.

For this fast convergence you need:

  • \(f'(r) \ne 0\): the curve crosses the axis at an angle instead of just touching it,
  • \(f\) is smooth (twice differentiable) near the root, and
  • the starting guess is close enough to the root.

When it slows down: repeated roots

If the curve only touches the x-axis, as \(f(x) = (x-1)^2\) does at \(x = 1\), then \(f'(r) = 0\) and the squaring no longer happens. For a root of multiplicity \(m\), each step only shrinks the error by a fixed factor:

\[ e_{n+1} \approx \left(1 - \tfrac1m\right) e_n. \]

For \((x-1)^2\), the error is cut in half each step. This is linear convergence, about 3.3 steps per digit, so it takes about 50 steps to get what \(x^2-2\) got in 5. If you know \(m\), the modified step \(x_{n+1} = x_n - m\,f(x_n)/f'(x_n)\) restores quadratic convergence.

When it fails

Newton's Method promises nothing if you start too far from a root. Some things that can go wrong:

A flat tangent
If \(f'(x_n) = 0\), the tangent is horizontal and never meets the x-axis. If \(f'(x_n)\) is only close to zero, the next guess shoots far away, possibly to a different root than the one you wanted. With \(f(x) = \cos x\), starting at \(0.1\) jumps out to the root near \(3.5\pi\).
Cycles
For \(f(x) = x^3 - 2x + 2\) starting at \(x_0 = 0\), the guesses go \(0 \to 1 \to 0 \to 1 \to \cdots\) forever, even though there is a real root near \(-1.77\).
Divergence
For \(f(x) = \sqrt[3]{x}\), the formula simplifies to \(x_{n+1} = -2x_n\). Every step lands twice as far from the root at 0 as the step before, no matter where you start. The curve is so steep near the root that each tangent overshoots.
Overshooting
With \(f(x) = \arctan x\), a start at \(x_0 = 1\) converges to 0, but \(x_0 = 1.5\) bounces back and forth with growing size and diverges. The cutoff is near \(x_0 \approx 1.3917\).
Surprising destinations
When there are several roots, the root you reach can depend on your starting point in complicated ways. For \(f(x) = x^3 - x\) (roots \(-1, 0, 1\)), starting at \(0.5\) lands on \(-1\), not on the nearer roots \(0\) or \(1\). Using this page

  • Type any function of \(x\), such as x^3 - 2x - 5, e^x - 3, sin(x) - x/2, or ln(x) - 1. The derivative is computed for you.
  • Use cbrt(x) for a cube root. Fractional powers like x^(1/3) also work for negative \(x\).
  • Add up to seven starting guesses to compare their paths. Click a guess's tab to see its table.
  • The address bar updates as you go, so you can copy the link to share a particular setup.
